# Grow Base — growbase.agency

Bilingual (English `/` · Albanian `/sq/`) marketing website for **Grow Base**, a boutique marketing studio in Tirana.
Plain static HTML/CSS/JS generated by a tiny zero-dependency Node script — no framework, no runtime, no trackers, no cookies.

## Deploy to Netlify (about 3 minutes)

**Option A — from GitHub (recommended: every push redeploys)**

1. Netlify → **Add new site → Import an existing project → GitHub →** pick this repository.
2. Choose the branch to publish (the *production branch*). Everything else is read from `netlify.toml`:
   build command `node scripts/build.mjs && node scripts/check.mjs`, publish directory `dist`, Node 22.
3. **Deploy.** The build also runs the quality gate (`scripts/check.mjs`); if anything is broken the deploy is refused instead of going live.

**Option B — drag & drop.** Run `npm run build` locally (Node 20+), then drag the generated `dist/` folder onto <https://app.netlify.com/drop>.

**Option C — CLI.** `npx netlify-cli deploy --prod --dir=dist` (needs a Netlify login or a `NETLIFY_AUTH_TOKEN` environment variable).

### After the first deploy

| Step | Where | Why |
|------|-------|-----|
| Attach the domain `growbase.agency` | Site configuration → Domain management | HTTPS certificate is automatic. The site already declares `https://growbase.agency` as canonical. If you use a different domain, set an environment variable `SITE_URL` (e.g. `https://example.com`) and redeploy. |
| Send form messages to your inbox | Site configuration → **Forms → Form notifications → Add → Email** → `info@growbase.agency` | The contact form is a Netlify Form named `contact`. Submissions are always stored in the Netlify dashboard (Forms tab); email alerts must be switched on once. Spam is blocked by a honeypot field plus Netlify's built-in filtering. |
| Submit the sitemap | Google Search Console → Sitemaps → `https://growbase.agency/sitemap.xml` | Both languages are listed with `hreflang` alternates. |
| Check the share cards | LinkedIn Post Inspector / any chat app | Social images live in `src/public/og/` (one per language). |

Only the **production branch** is indexable. Branch deploys and deploy previews automatically get `noindex` + `Disallow: /`.

## Editing

| What | File |
|------|------|
| All copy, English | `src/content/en.mjs` |
| All copy, Albanian | `src/content/sq.mjs` (must keep the same structure — the build checks this) |
| Email, phone, address, social links, URL slugs | `src/site.mjs` |
| Page layouts | `src/pages.mjs`, `src/layout.mjs` |
| Look & feel (colours, type, spacing) | `src/styles/main.css` (brand colours are CSS variables at the top) |
| Behaviour (menu, form) | `src/scripts/main.js` |

Content strings support `*italic*`, `**bold**`, `[link](https://…)` and `[link](@privacy)` (link to a page by route name).

```bash
npm run dev      # build + preview at http://localhost:4173
npm test         # build + quality gate
```

### What the quality gate checks (`scripts/check.mjs`)

EN/SQ translation parity · one `<h1>` per page · title/description lengths · every image has `alt` + dimensions ·
broken links, assets and `#anchors` · `hreflang` reciprocity and canonical URLs · JSON-LD validity ·
contact-form markup identical in both languages · CSP hash matches the inline boot script · no inline styles/handlers (CSP) ·
sitemap completeness · WCAG AA contrast of every brand colour pairing · CSS/JS size budgets.

### Regenerating assets (rarely needed)

`tools/make-assets.py` rebuilds the vector logo, favicons and responsive painting crops from `assets-src/`
(`pip install pillow numpy potracer`). `tools/make-og.mjs` rebuilds the 1200×630 share images (needs Playwright).

## Design notes

* **Brand**: palette sampled from the supplied palette image — ink `#1a1612`, charcoal `#3a3530`, copper `#c97a2a` (logo `#c17c3a`), bronze `#8a4f0a`, cream `#f2ede4`, parchment `#e8dcc8`. Typeface Times New Roman, with the metric-compatible **Tinos** (OFL) self-hosted as fallback for devices without it (it only downloads when needed).
* **Concept — "gallery after dark"**: Claude Lorrain's *Seaport with the Embarkation of the Queen of Sheba* (1648, National Gallery, London) for launches/clear headings, and François Lemoyne's *Apotheosis of Hercules* (1736, Versailles) for growth-as-ascent. Both are public domain; higher-resolution scans were fetched from Wikimedia Commons (credits in `assets-src/art/CREDITS.md` and on the site's Terms page). Arches echo the paintings' architecture and the logo's roundness.
* **Accessibility**: semantic landmarks, skip link, visible focus, full keyboard use, `prefers-reduced-motion` respected, works without JavaScript, 0 axe-core violations (WCAG 2.2 AA) across all pages at desktop and mobile widths.
* **Privacy/security**: no cookies, no analytics, no third-party requests (fonts self-hosted, no map embed). Strict Content-Security-Policy and other security headers are generated into `dist/_headers`.

## Legal content — please review

The Privacy Policy, Cookie Notice and Terms were drafted from research (Albanian Law No. 124/2024 on personal-data protection, aligned with the GDPR; the Commissioner for the Right to Information and Protection of Personal Data) but are **not legal advice**. Before launch, have an Albanian lawyer confirm:

* the **legal entity name and registration number (NUIS/NIPT)** — not provided, so deliberately left out rather than invented; Albanian e-commerce rules expect service-provider identification on commercial sites, so add them to the "Legal notice" in `src/content/*.mjs` (`legal.terms.sections[0]`);
* the stated **retention period** (24 months for unanswered enquiries) and the list of processors (Netlify, your email provider);
* if you later add analytics, advertising pixels (Meta/Google/TikTok/LinkedIn) or embeds, you will need a **consent banner** and updated Cookie/Privacy pages — the current "no cookies" statements are only true while none are added.

The "Our work" section describes the *kinds* of results from your copy without invented clients, figures or testimonials. When real case studies exist, add them with figures you can substantiate.
